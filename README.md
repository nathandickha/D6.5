# Atelier 3D / AquaVision static website

This package recreates the supplied Base44 visual design as a standalone static website.

## Local preview
Run from the `D6.3-main` folder:

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.

## GitHub Pages
Upload the contents of `D6.3-main` to the repository root. All marketing-site paths are relative and GitHub Pages compatible.

The existing `pool-designer-app` folder and its Three.js logic were preserved.
